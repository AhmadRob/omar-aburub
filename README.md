# Omar Abu Rub · Portfolio

Personal site of Omar Abu Rub (عُمَر أَبُوالرُّب), full-stack developer and software engineer in Amman. Co-founder of ByteGene, software engineering at ASU.

A single, dependency-free HTML page in the spirit of Ghost of Yōtei:

- **Ink rail and red seal** down the side instead of a nav bar; hold anywhere (or press 図) to open the map of chapters.
- **Onryō mode**: a night storm with lightning, a different portrait and a taiko-driven score, all synthesized live with the Web Audio API (shamisen, shakuhachi, taiko, strings).
- **Arsenal** of Atsu's weapons, drawn in ink as you scroll.
- **English and Arabic**, with full right-to-left mirroring.
- A hidden campfire in 3D. Type `takibi`.

## Publish on GitHub Pages
1. Upload everything in this folder to the root of the repository (keep the `img` folder).
2. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)** → Save.

Fonts load from Google Fonts; the 3D campfire loads three.js from jsDelivr when opened.
